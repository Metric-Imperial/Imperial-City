# Item icon generation prompts

Grouped batches for the outstanding imperial-authored items. Generate each
group in one session so the set stays visually consistent.

Items marked **[unused]** are defined in the catalogue but referenced by no
resource — either planned-but-unbuilt or vestigial. Defer until play testing
confirms they get implemented.

## Shared style block

Prepend this to every batch:

```
Video-game inventory icons, drawn as a matching set.

Style: bold comic-book / cartoon illustration. Heavy dark outline around the
whole object, flat cel-shaded colouring with simple hard-edged highlights and
shadows, saturated but grounded palette. Clean and readable at small size.
Slight 3/4 angle. Subtle soft drop shadow beneath the object.

Background: fully transparent (alpha channel). No scene, no ground plane, no
border, no frame, no text or labels unless the object itself carries lettering.

Framing: single object, centered, filling roughly 80% of a square 1:1 canvas
with even margin.

Render at 1024x1024, then downscale to 100x100 PNG with transparency.
```
